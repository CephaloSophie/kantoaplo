        Les questions du publicQuestions from the audience

        Avant le lever de rideau.Before the curtain rises.

        Qu'est-ce que KANTO APLO ?What is KANTO APLO?

        KANTO APLO est une plateforme SaaS no-code / low-code conçue par Cephalo Sophie. Elle réunit douze éditeurs visuels — interface, services et APIs, modélisation UML, blocs, tests d'API, gestion de projet agile, analyse web, tests A/B, connecteurs et orchestration — pour créer des applications métier complètes sans écrire de code.KANTO APLO is a no-code / low-code SaaS platform built by Cephalo Sophie. It brings together twelve visual editors — interface, services and APIs, UML modelling, blocks, API testing, agile project management, web analytics, A/B testing, connectors and orchestration — to build complete business applications without writing code.

        Faut-il savoir programmer ?Do I need to know how to code?

        Non. Tout se compose par glisser-déposer et configuration. Pour les équipes techniques, chaque éditeur reste ouvert : sortie JSON, code généré, documentation OpenAPI, plugins.No. Everything is composed by drag and drop and configuration. For technical teams every editor stays open: JSON output, generated code, OpenAPI documentation, plugins.

        Quelles applications peut-on créer ?What can I build?

        Des applications web et mobiles, des sites, des funnels et des quiz, des APIs REST et des tâches planifiées, des workflows d'automatisation, des back-offices et outils internes, des tableaux de bord analytiques, des éditeurs visuels propres à votre métier.Web and mobile apps, websites, funnels and quizzes, REST APIs and scheduled jobs, automation workflows, back offices and internal tools, analytics dashboards, and visual editors dedicated to your business.

        Peut-on essayer les éditeurs ?Can I try the editors?

        Oui : le bouton « Écouter la symphonie » ouvre la démo interactive de chaque éditeur, avec des données fictives. Pinax (gestion de projet agile) et Mantis (analyse web) se testent avec l'e-mail demo@kantoaplo.com ; vos modifications restent dans votre navigateur.Yes: the “Listen to the symphony” button opens each editor’s interactive demo, with fictional data. Pinax (agile project management) and Mantis (web analytics) can be tried with the e-mail demo@kantoaplo.com; your changes stay in your browser.

        Peut-on obtenir un éditeur sur mesure ?Can I get a custom editor?

        Oui, c'est « Composer votre symphonie » : nous concevons avec vous un éditeur visuel dédié à votre métier, bâti sur Zeugma et le moteur KANTO. Écrivez à contact@cephalosophie.com.Yes, that is “Compose your symphony”: we design with you a visual editor dedicated to your business, built on Zeugma and the KANTO engine. Write to contact@cephalosophie.com.

        Où restent mes données ?Where does my data live?

        Mantis, l'analyse web, est conçu pour être auto-hébergé : les statistiques restent sur votre serveur, sans cookie tiers. Pour les autres éditeurs, le mode de déploiement se choisit avec vous.Mantis, the web analytics editor, is designed to be self-hosted: statistics stay on your server, with no third-party cookies. For the other editors, the deployment mode is chosen with you.

        Pourquoi des noms grecs ?Why Greek names?

        Κάντο απλό signifie « rends-le simple ». Chaque éditeur porte le mot grec de son rôle : Tektôn le bâtisseur, Logos la règle, Pinax le registre, Mantis le devin, Hermès le messager…Κάντο απλό means “just make it simple”. Each editor bears the Greek word for its role: Tektôn the builder, Logos the rule, Pinax the ledger, Mantis the seer, Hermès the messenger…
